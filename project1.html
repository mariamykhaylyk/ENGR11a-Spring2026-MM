Name Tag: My First 3D Print

My first 3D print is a key tag with my name on it. It's to get access to other 3D printers on campus. I appreciated the walkthrough for this process from start to finish in class because simply finding the download button for the print template could have been difficult if I didn't know where to look! Additionally, I learned how to feed the philament properly until the Prusa Mini+ machine "grabbed" it, and how to switch out colors, which was fairly simple as long as you know how to control the printer pad's settings with the knob. Finally, popping the final print off the heatbed was super satisfying! Here are a few detailed notes and images I took during the process:

a. I originally put “General” not “Input Shaper” in the settings for the Prusa Printer software, which was the incorrect printer category, so I got a warning message when trying to start printing and had to fix the settings and redownload my file.

b. The printer started the print with an outline of the nametag, which I learned is to help us calibrate the print.

c. In the end, the name tag looked great but was stringy and had a few holes/divits in some places. The back looked perfect though, perhaps because I wiped down the heatbed before using it.
