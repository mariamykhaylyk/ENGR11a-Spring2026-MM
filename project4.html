Website Creation

This website was a project in itself! The process was a bit bumpy in terms of understanding a new coding language and getting the website up and running with GitHub. However, I am happy with the result, and will keep updating and building on what the template has to offer!

The images below show my file organization and how I sync my coding changes to my working website. In my files, I mostly use the .html files and the folder named "assets" (which is where I store my images). I edit code on Sublime Text. When I make edits, I make sure to into my GitHub Desktop app and "commit" my changes and "push origin", as seen is the screenshot below. This updates my public website!

Throughout the process, I learned a lot through searching online and using AI to answer my questions. Getting hands on experience is great!
